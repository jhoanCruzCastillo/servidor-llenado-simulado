# Skill `llenar-fichas-mef` en este servidor

Está instalada como skill de proyecto (`/llenar-fichas-mef`). Cárgala cuando el trabajo sea llenar o revisar una ficha técnica MEF / Invierte.pe.

En **esta** sesión no ejecutes `scripts/*.py` ni LibreOffice: no hay Bash. Usa las reglas de la skill (solo celdas de entrada, listas exactas, no tocar fórmulas, discrepancias se reportan) y entrega con las herramientas del servidor (`llenar_campos` / `llenar_tablas`, o el JSON que te pidan).

Las notas de `fichas/<CÓDIGO>/` mandan sobre intuición. Hoy hay mapa completo de FTE-EBR-V03.

Si el trabajo es **modo Skill MEF**, no leas `estructura.json` ni `05_secciones_a_llenar`: no están en tu directorio. Usa la skill, el Excel en blanco, el Excel de ejemplo, los PDFs y el chat del asesor.
